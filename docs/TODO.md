# Agent 教学网站开发 Todo

## 1. 产品目标

- 把官方文档、设备手册、API 手册等枯燥资料转成可理解的教学页面。
- 页面输出不只是摘要，而是包含：核心概念、流程图、具象动画、互动 demo、关键参数实验。
- 动画风格参考清晰的数学/工程教学视频：对象可见、因果关系明确、步骤逐帧展开、文字只做辅助说明。
- 视觉方向采用赛博朋克教学控制台：高对比、霓虹边线、深色背景、数据面板、扫描线、仪表式控件。

## 2. MVP 功能清单

- 文档输入
  - 支持粘贴文本。
  - 后续支持 PDF、Markdown、HTML、网页 URL。
  - 对长文档做章节切分、标题识别、表格抽取、参数抽取。

- 内容理解
  - 提取文档类型：设备手册、API 文档、算法说明、操作指南。
  - 提取核心对象：例如小车、激光雷达、障碍物、控制器、传感器数据。
  - 提取流程关系：输入、计算、判断、输出、异常处理。
  - 提取可互动参数：速度、检测半径、阈值、重试次数、接口状态等。

- 教学分镜生成
  - 每个章节生成 3 到 7 个教学镜头。
  - 每个镜头包含：画面对象、对象状态、运动规则、旁白文字、交互点。
  - 避免只生成大段文字，必须至少生成一个可视化模型。

- 动画生成
  - 用 Canvas/SVG/Three.js 生成可控动画。
  - 支持时间轴播放、暂停、重播、单步推进。
  - 支持参数滑杆实时改变动画结果。
  - 常见模板库：避障、请求链路、状态机、电路、坐标系、队列、调度器、数据库事务。

- 互动 demo
  - 至少生成 1 个核心交互 demo。
  - 对硬件/机器人类文档，优先做对象演示：设备、传感器、环境、信号、控制动作。
  - 对 API 类文档，优先做请求流、鉴权、错误重试、数据结构变换。
  - 对 ROS 类文档，优先做知识图谱和运行时通信动画：Node、Publisher、Topic、Subscriber、Message、源码关联、机器人状态。

- 交互式知识电影
  - 用滚轮或时间轴推进镜头。
  - 每个镜头触发对象出现、消息流动、节点高亮、源码联动或模拟状态变化。
  - 用户点击画面对象时，应看到相关源码、参数、运行状态或拓扑关系。

## 3. 技术架构建议

- 前端
  - 正式版本采用 React + Next.js。
  - Tailwind CSS + shadcn/ui + Framer Motion 做赛博朋克 UI 和微交互。
  - GSAP + ScrollTrigger 做滚动叙事。
  - React Flow 做知识图谱和 ROS 拓扑。
  - Canvas/Rive/Motion Canvas 用于 2D 动画，Three.js/React Three Fiber 用于 3D 设备或空间场景。
  - 动画状态机用 XState 或轻量自研 timeline。
  - UI 使用设计系统组件，统一控制面板、时间轴、参数控件。

- 后端
  - 文档解析服务：PDF/HTML/Markdown 转结构化块。
  - Agent 编排服务：先理解文档，再生成分镜，再生成动画规格。
  - 动画规格 JSON：前端只消费结构化 spec，不直接执行模型输出代码。
  - 资源服务：生成或检索图片、图标、材质、示意物体。

- 模型调用
  - 第一步：文档解析和摘要。
  - 第二步：概念图谱与流程提取。
  - 第三步：生成教学分镜。
  - 第四步：生成动画 spec，而不是直接生成不可控网页代码。
  - 第五步：前端渲染 spec，并允许用户修改参数。

## 4. 动画质量标准

- 每个动画必须回答一个明确问题，例如“为什么小车会转向避障”。
- 每个关键概念必须对应一个可见物体或状态变化。
- 物体之间的关系要可见，例如射线命中障碍、距离低于阈值、控制器输出转向。
- 文案只解释因果，不重复视觉上已经明显的东西。
- 交互参数必须改变结果，而不是只改变 UI 数值。

## 5. 小车避障 Demo 标准

- 必须展示：小车、车头方向、激光雷达扫描线、障碍物、安全距离、路径轨迹。
- 必须展示：扫描、检测、决策、转向、通过障碍五个阶段。
- 支持调整：车速、雷达半径、障碍物密度、安全距离。
- 支持交互：拖动障碍物、暂停/播放、重置、查看单步解释。
- 当障碍进入危险区时，动画必须明确展示触发原因和避障动作。

## 6. 需要额外配置

- 如果只是做 2D 教学动画：浏览器、Canvas/SVG、无需额外系统配置。
- 如果要自动读取 PDF：需要后端 PDF 解析库，例如 pdf-parse、PyMuPDF 或 unstructured。
- 如果要从 URL 抓取官方文档：需要后端抓取服务和网络权限。
- 如果要生成高质量插图或纹理：需要图片生成模型或素材库。
- 如果要生成 3D 设备演示：需要 Three.js，并准备 glTF/GLB 模型资源。
- 如果要让 Agent 自动产出可执行动画：需要定义安全的动画 JSON schema，避免直接运行模型生成的任意代码。

## 7. 当前原型范围

- 先做静态前端 demo，验证体验方向。
- 内置一份“小车避障手册片段”。
- 内置一份“ROS Publisher/Subscriber 手册片段”。
- 页面包含文档输入区、Agent 分析结果、教学分镜、互动 Canvas 动画。
- 动画用真实对象演示核心逻辑，不只展示文字。
- ROS demo 已实现最小交互知识电影：滚轮推进、Topic 消息飞行、点击 Topic 查看源码、点击源码高亮节点、拖动机器人模拟。
